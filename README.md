Twinfold is an artisanal procedural spot-the-difference puzzle game built for the browser with zero external dependencies. Features four hand-crafted vector worlds (Lighthouse Harbor, Night Bazaar, Greenhouse Lab, and Clockwork Attic), procedural WebAudio soundscapes, dual-panel responsive rendering, and accessible controls.
