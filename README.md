Twinfold is an original spot-the-difference game drawn entirely in code: four illustrated scenes (Lighthouse Harbor, Night Bazaar, Greenhouse Lab, Clockwork Attic) with growing subtlety, a timer you can feel, hints, combos, synthesized sound and full keyboard play. It runs offline from static files.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
